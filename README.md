# 🚀 Portal de Juegos Educativos 🎮

¡Bienvenidos a este repositorio! Este es un portal web de código abierto diseñado para alojar juegos educativos interactivos dirigidos a niños y niñas de nivel primario (**de 6 a 13 años**). 

El objetivo es transformar el aprendizaje escolar en una experiencia divertida, visual y dinámica a través de la tecnología web.

## 🌟 Características del Portal
- **Diseño amigable e infantil:** Interfaces limpias, luminosas y adaptadas para infancias.
- **Multiplataforma:** Accesible desde computadoras, tablets y celulares sin necesidad de descargas.
- **100% Gratuito y Libre:** Aloja herramientas pedagógicas de acceso público para docentes, familias y alumnos.

## 🕹️ Juegos Disponibles
1. **[Maestro de los Decimales](juegos/decimales/index.html):** Un recorrido de 5 niveles para practicar lectura, escritura, fracciones decimales, sumas y restas con temáticas espaciales, deportivas y de la naturaleza.
